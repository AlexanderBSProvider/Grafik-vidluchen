# Тетріс відключень

Вебгра «Тетріс», у якій ігрове поле — це графік відключень світла: черги 1.1–6.2, години 00-01…23-24, сірі клітинки «Світла немає» та легенда під таблицею.

## Як грати

Відкрийте `index.html` у браузері. Нічого встановлювати не треба: це один файл без залежностей.

Фігури складаються з клітинок «Світла немає». Коли рядок графіка повністю заповнений, він зникає, і в ньому «повертається світло».

- **Горизонтальний графік** (як в оригіналі): поле 24 × 12, рядки — черги. Зникає черга, вимкнена на всю добу.
- **Вертикальний графік** (кнопка «Повернути»): поле 12 × 24, рядки — години. Зникає година, коли вимкнені всі черги.

Поки гра не почалася, на полі показано графік на 25.12.2024, з половинками «перші / другі 30 хв.».

## Керування

| Клавіша | Дія |
| --- | --- |
| ← → | рух |
| ↑ або X | поворот за годинниковою стрілкою |
| Z | поворот проти годинникової стрілки |
| ↓ | швидше вниз |
| Пробіл | скинути одразу |
| C або Shift | відкласти фігуру в запас |
| P або Esc | пауза |
| Enter | почати / продовжити |

На телефоні під полем з'являються кнопки керування.

## Правила

- Повороти та відштовхування від стінок за системою SRS, «мішок» із 7 фігур, тінь фігури, запас, затримка перед фіксацією.
- Очки: 100 / 300 / 500 / 800 × рівень за 1–4 рядки (у горизонтальному режимі ×2, бо рядок удвічі довший), +1 за кожну клітинку прискореного падіння, +2 за скидання.
- Новий рівень кожні 10 рядків (у горизонтальному режимі кожні 5). Назва рівня змінюється від «стабілізаційних» до «аварійних» відключень.
- Рекорд зберігається в браузері окремо для кожного режиму.
- Гра закінчується «блекаутом», коли нова фігура не вміщується вгорі графіка.
